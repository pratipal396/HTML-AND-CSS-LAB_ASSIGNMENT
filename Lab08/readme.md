Lab 8: Sign-Up Forms and Choices


Aim Build a form with text inputs, radio buttons, a dropdown and validation.

Theory

collects user input. action is where data is sent and method is get or post.
is linked to . Clicking the label focuses the input.
Input types: text, email, password. Radio buttons with the same name form one group (only one can be selected).
with makes a dropdown. sends the form. placeholder shows a hint. required stops submission if the field is empty. type="email" checks the email format. Files in this folder signup.html: Name, email, password and Sign Up button. choices.html: Gender radio buttons and course dropdown. signup-required.html: Form with placeholder and required fields.
